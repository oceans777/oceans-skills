## 需求文档生成约束

当用户明确要求撰写、整理成或更新需求文档时，调用 `prd-blueprint`（需求文档生成技能）。
普通讨论、仅提及文档、只读审查、只要求开发或明确要求暂不写文档时，不启动生成流程。
交付独立三项总纲和完整需求文档，对话中原样展示总纲。详细文档必须逐项服从总纲。
写文档不等于确认需求，也不等于授权业务开发；更新已确认需求必须展示总纲差异并保留旧基线。
技能缺失、未加载或文件不可读时明确报告；依相同三项格式尽力完成，但不得声称技能已加载。
本规则不创建定时任务，不承诺每半小时核查已经启用。
