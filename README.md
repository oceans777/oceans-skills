# oceans777 First-Party Skills

This repository contains skills created or primarily maintained by oceans777.

Skills live under:

```text
skills/<skill-name>/
```

Each skill must include:

```text
SKILL.md
```

Optional supporting folders:

```text
scripts/
references/
assets/
agents/
```

Use lowercase letters, digits, and hyphens for skill names.

## 需求文档生成技能

`prd-blueprint`（需求文档生成技能）：明确要求写需求文档时，生成三项总纲和完整详细文档，并逐项核对功能与验收。

[使用说明与验收依据](docs/prd-blueprint/README.md)。安装通过 [统一入口](https://github.com/oceans777/skills)，生效状态以入口目录为准。
