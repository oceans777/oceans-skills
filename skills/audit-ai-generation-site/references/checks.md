# 可验证检查目录

使用范围：AI 图片/视频收费生成服务。C = CASE-XUXUAN-20261019 作者材料陈述；D = 工程推导，不归因给原作者。以下均为检查候选，不是对目标站的既成发现。每项执行时填入项目状态和证据；无运行证据不能声称运行层通过。

## PAY-01 支付确认与账户归属
- 适用：托管结账、支付 webhook、充值或订阅。
- 来源/证据状态：D；案例 C 报告支付后入口和到账提示问题，但未证明 webhook 漏洞。
- 症状：浏览器显示付款成功但无权益，重复通知重复充值，别人的订单可被领取。
- 检查：服务端校验签名、原始请求体、商户/环境、金额、币种、商品及账户归属；以服务端最终支付状态确认到账，不信任 success URL 参数。覆盖延迟、重复、乱序及失败付款；将供应商事件唯一性与订单业务唯一性分开处理。检查对账补偿入口。
- 修复方向：可信事件驱动、幂等持久记录和事务性权益变更；成功页能显示“确认中”，而不是擅自补发。
- 回归：沙箱重复/乱序事件不重复到账；伪签名、错误金额/账户被拒；支付取消不充值；延迟事件最终到账。订阅适用时另测续费/取消/周期边界。

## AUTH-01 跨登录/付款状态与下一步
- 适用：登录或支付会离开生成页面。
- 来源/证据状态：C；未经目标项目验证。
- 症状：照片丢失、已付款却没有开始、找不到生成入口。
- 检查：返回地址校验；匿名草稿如何安全绑定到登录用户；照片及模型选项能否恢复；过期草稿、切换账号、刷新/返回/多标签页；付款与提交生成是否为两个明确状态。
- 修复方向：有生命周期和所有权校验的草稿；明确显示到账状态及下一步。不要把私密照片或凭据塞入 URL。
- 回归：登录/取消付款/完成付款后状态合理；切号不泄漏前账户素材；重复返回不重复生成。

## CREDIT-01 积分、预留与补偿幂等
- 适用：积分计费、按次付费或失败退额度。
- 来源/证据状态：C 报告余额/分辨率错配和卡单退积分；原子账本/并发保护为 D。
- 症状：扣两次、负余额、超时退后迟到成功免费交付、重复退款。
- 检查：服务端计算价格和选项；预留/扣除/释放/退款状态清晰；并发请求、双击及重复回调不能绕过余额。区分退积分与支付现金退款；验证本地状态和外部退款结果一致。
- 修复方向：事务/条件更新、不可重复的业务键和可对账账本；补偿也需幂等，按产品政策处理迟到成功，避免二次补偿。
- 回归：并发提交余额不足时只允许可付任务；重复完成/失败/退款不重复记账；分辨率切换正确计价；退款请求结果不明时先查状态，不盲目重试。

## JOB-01 异步状态机、队列与恢复
- 适用：耗时生成、队列、供应商轮询或回调。
- 来源/证据状态：C 报告 pending 和长请求；持久队列/恢复设计为 D。
- 症状：请求断开即丢任务，工作进程重启后永远 pending，同一任务调用多次。
- 检查：持久任务 ID、供应商关联 ID、合法状态转换；提交后迅速返回可查询状态；worker 领取租约、去重、背压、取消能力及恢复扫描。供应商接收成功但响应丢失时，重提是否会重复收费？
- 修复方向：持久异步执行与可恢复状态机，独立幂等边界；按供应商能力查询/对账再重提。没有幂等能力且结果未知时保留人工处理，不伪造 exactly-once 保证。
- 回归：worker 重启/租约到期/回调重复乱序/提交响应丢失均能恢复；不重复扣费或创建供应商任务；错误状态转换被拒。

## JOB-02 超时、重试分类与迟到结果
- 适用：所有外部生成/存储请求。
- 来源/证据状态：C 报告延长超时和卡单补偿；可靠策略为 D。
- 症状：网络抖动被判最终失败；无限重试增加成本；成功任务误退积分。
- 检查：区分客户端等待、请求截止、队列等待、执行 SLA；超时不等于供应商失败。明确可重试暂态错误、结果未知、永久拒绝；退避、抖动、次数/总时长/费用预算及告警；处理终态之后到达的成功。
- 修复方向：按服务合同和观测数据设置时间预算；状态查询/补偿流程先于盲目重做；对未知结果标待核实。
- 回归：模拟 429/5xx/断网/无回调/迟到成功，验证重试有界、未知状态可追踪、不会双退双扣。不能仅把 30 秒改成 200 秒即宣称修复。

## INPUT-01 输入归一化与可操作提示
- 适用：照片/视频/音频上传。
- 来源/证据状态：C 报告比例、像素、多人、墨镜和提示问题；文件安全边界为 D。
- 症状：上传后反复失败但无原因；错误旋转/裁剪；伪装格式或超大文件耗尽资源。
- 检查：真实内容类型、解码成功、大小/像素/时长/比例、EXIF 方向、色彩及供应商当前规格；客户端提示与服务端校验一致。裁剪会否损失关键人物，是否应让用户预览？不要复制固定 300px。
- 修复方向：可预测归一化和针对性提示；限制解码资源，使用合成素材测试；不要在日志保存原图。
- 回归：旋转照片、极端比例、透明图、损坏/伪 MIME/大图、多人物均有预期结果；不把输入错误当网络错误重试。

## MOD-01 安全/版权拒绝不是暂态错误
- 适用：供应商审核、版权或人脸相关限制。
- 来源/证据状态：C 报告审核拒绝反复失败；不得绕过审核是执行边界。
- 症状：拒绝后无穷重试、提示“网络失败”、重复收费。
- 检查：拒绝代码映射明确，停止自动重试；区分可修正输入错误与明确安全/版权拒绝。不能换供应商、改提示词或重复同一素材来规避拒绝。
- 修复方向：明确且适度的用户提示、任务拒绝终态、按政策补偿；保留合法安全防线。
- 回归：用 mock 拒绝响应验证不再次提交、不重复收费、显示正确原因。不需要真实违规素材触发审核。

## OUTPUT-01 结果质量与误判边界
- 适用：相似度/质量评分、自动失败或自动退款。
- 来源/证据状态：C 报告相似度误杀；质量指标设计为 D。
- 症状：有效成片被退掉；用户反复同图付费；无声/损坏结果算成功。
- 检查：区分文件完整性（可解码、时长、音轨按承诺存在）与主观像不像；评分阈值有无自家标注样本，误判率及可解释提示；低置信结果不得触发失控重试。
- 修复方向：确定性完整性检查与可选质量提示分层；先离线验证再启用高影响自动动作；提供合理支持入口。
- 回归：好结果、低相似但有效结果、损坏文件、缺音轨分别正确处理；主观评价不能重复触发昂贵任务。

## STORE-01 持久保存、权限与有效期
- 适用：供应商临时 URL、对象存储、下载签名。
- 来源/证据状态：C 报告 R2 保存失败及上游链接过期；权限/生命周期为 D。
- 症状：付款后暂能播放，几小时后文件消失；其他账户可访问结果。
- 检查：交付成功是否等待存储验证；下载抓取仅允许可信供应商目标，避免任意 URL/重定向造成 SSRF；存储失败重试有界；内容类型、长度/哈希或可解码性；对象所属用户和签名 URL；保留政策、删除及备份生命周期。
- 修复方向：自有可控存储后再确认可交付；可追踪保存失败；明确保留期，不把永久公开存储当默认。链接过期可经身份验证再生成。
- 回归：模拟上游链接过期、存储短暂失败、签名到期与跨账户读取；可恢复且不泄漏。不能承诺文件“永久保存”而没有产品和成本依据。

## MOBILE-01 移动上传、付款、下载闭环
- 适用：移动 Web、内嵌浏览器或移动钱包。
- 来源/证据状态：C 报告遮挡、下载障碍和设备转化差异；因果未证实。
- 症状：按钮不可点、只能播放不能保存、付款后回跳异常。
- 检查：真实目标设备/浏览器视口、安全区、软键盘、相册选择；有权限时用支付沙箱测取消/成功回跳；下载的 Content-Disposition、Content-Type、同源/CORS、CDN 规则及签名；OS 支持的分享/保存路径和失败提示。
- 修复方向：按实际设备问题修复布局和响应头，不因 Android 转化低就断言支付原因。不可声称所有浏览器都可“一键存相册”。
- 回归：记录 iOS Safari/Android Chrome 等实际覆盖矩阵；桌面仿真不等于真实手机通过；完整上传→返回→查看→下载至少在目标设备验证。

## DEPLOY-01 构建产物与运行环境
- 适用：ffmpeg/原生二进制、pnpm、serverless 或容器。
- 来源/证据状态：C 报告 ffmpeg 软链接部署问题；跨环境验证为 D。
- 症状：本地可用，生产文件缺失、无执行权限或架构不符。
- 检查：检查实际构建产物而非仅源码路径；软链接目标是否随包存在，执行权限、OS/CPU/动态库、运行时限制、临时盘和许可证要求。
- 修复方向：按平台支持方式打包依赖；不要无条件改为复制文件或增大函数超时。
- 回归：在匹配部署环境运行合成媒体 smoke test，验证产物调用和输出；仅本地 ffmpeg --version 不足以证明线上可运行。

## DB-01 连接池与并发容量
- 适用：数据库连接型后端、serverless 扩缩容。
- 来源/证据状态：C 作者将 500 归因连接耗尽；具体数据库未确认。
- 症状：并发上涨后 500、连接超限、请求挂起。
- 检查：函数实例数×池大小是否超总连接预算；连接释放、事务时间、生成期间是否占连接、超时与池代理；监控连接数和等待。
- 修复方向：结合数据库/平台选池化或代理及有界并发；不靠无限增大连接数缓解。
- 回归：授权的隔离环境负载测试，加上异常退出/回滚，验证连接回落和请求可控失败；不可无授权对生产压测。

## DELIVERY-01 结果历史与通知
- 适用：长任务完成后离站用户、邮件或站内通知。
- 来源/证据状态：C 报告“我的视频”、通知入口及支持邮箱改进；幂等通知为 D。
- 症状：已生成用户不知道；邮件指向失效链接；回调重复轰炸用户。
- 检查：任务历史按身份隔离，状态及时；通知只在可交付后触发，发件人配置、可回复支持渠道、链接鉴权与有效期；通知失败不重跑生成；送达与发送接受分开统计。
- 修复方向：幂等通知/outbox 或同等可靠机制；用户可通过历史找到结果，不依赖一次邮件。
- 回归：mock 邮件服务验证重复回调只发一次、失败可独立恢复、链接访问不越权。没有授权不发真实客户邮件。

## LIMIT-01 成本、反欺诈与合理限额
- 适用：收费模型、购买、重试及免费试用。
- 来源/证据状态：C 报告随意生成次数限制及后来反盗刷限购；预算和威胁建模为 D。
- 症状：付费权益被无依据阻断、重试放大成本、滥用账户拖垮服务。
- 检查：限制是否来自明确产品政策；账户/IP/并发/供应商预算、单任务重试预算、支出告警和停损路径；核算模型费用、失败、退款、税和支付费而非只看营收；后台操作鉴权。
- 修复方向：删除意外限制与保留合法风控分开；限额应可配置、可观测、向用户解释，与已售权益兼容；不要照抄 $150 或全站次数。
- 回归：正常已付用户可用权益；并发/滥用触发预期限制；边界不会多扣费；预算耗尽能有序暂停，不形成无限自动恢复循环。

## PRIVACY-01 照片隐私、访问控制与权利边界
- 适用：任何用户上传、人脸或第三方媒体生成。
- 来源/证据状态：D；来源案例没有证明已完成这些控制。
- 症状：公开原图、日志含签名 URL/凭据、他人可读任务、未经许可长期保留素材。
- 检查：所有任务/素材/结果 API 的租户归属与对象级授权；上传和结果访问范围；存储保留与删除、第三方供应商数据用途及地域要求；用户对素材/人物/音视频的使用权说明与投诉入口；秘密仅服务端管理。
- 修复方向：最小访问、最少保留、脱敏日志和清晰告知；发现法律适用问题说明待专业确认，技术检查不冒充合规认证。
- 回归：用合成数据及两个测试账户验证越权拒绝、删除后不可继续取得内容、日志无敏感正文。不得以审计名义下载无关真人素材。

## OBS-01 可观测链路与错误归因
- 适用：所有生产链路；SEO 项只在相应范围内检查。
- 来源/证据状态：C 报告漏斗、等待预估、sitemap；关联追踪为 D。
- 症状：只知流量和收入，不知用户卡在哪；技术成功与交付混为一谈。
- 检查：关联订单/用户/任务/供应商 ID（脱敏）；支付确认、生成提交、执行完成、存储完成和下载分别计数；事件去重、漏斗分母、设备/来源拆分及样本量；卡单和失败告警可定位；等待区间基于真实分布而非固定抄值。
- 修复方向：最小必要埋点，避免记录照片或完整提示；优先服务端资金和任务事件。若检查 sitemap/索引，验证可访问和格式，不承诺被收录；llms.txt/IndexNow 非已证明增长保障。
- 回归：隔离场景可串联并定位故障，重复事件不虚增收入；无配置或无日志写 not-verified，而不是“未发现问题”。
